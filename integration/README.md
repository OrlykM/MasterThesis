# Карта довіри: сервер і клієнт

У теці два боки одного конвеєра.

| файл | хто запускає | що робить |
|---|---|---|
| `server_simple.py` | **ти** | приймає кадри, будує карту довіри, віддає назад |
| `client.py` | той, хто шле | шле кадри, приймає карту |
| `example.py` | той, хто шле | найкоротший приклад на один кадр |

---

## Якщо ти ПРИЙМАЄШ (запускаєш сервер)

```bash
python server_simple.py --fake          # спершу на заглушках, перевірити зв'язок
python server_simple.py                 # коли вставив свої VSLAM і FDE
python server_simple.py --tcp           # якщо джерело в іншій мережі
```

Сервер сам розрізняє два випадки:

| що прийшло в кадрі | що робить сервер |
|---|---|
| **лише картинка** | кличе твою `my_vslam_and_fde()`, щоб порахувати глибину, позу і точки |
| **картинка + глибина + поза + точки** | бере готове, нічого не рахує |
| щось посередині | рахує лише те, чого бракує |

У `server_simple.py` є рівно одне місце, позначене `ТУТ ТВІЙ КОД`. Встав туди
виклики свого VSLAM і FDE, поверни словник з тим, чого бракувало. Решту файлу
чіпати не треба.

Поки свого коду немає, запускай з `--fake`: замість справжніх VSLAM і FDE
підставляються вигадані, але правдоподібні числа, і видно, що кадри ходять
туди й назад.

Вивід на кожен кадр виглядає так:

```
кадр    1  у карту  56% пікселів, довіра 1.00, змінено 822 вокселів, усього зайнято 430
```

## Якщо ти ШЛЕШ (запускаєш клієнт)

Ти шлеш кадри на один порт, назад на інший порт приходить карта довіри.
Потрібен лише `numpy`, увесь код в одному файлі `client.py`.

```bash
pip install numpy
python client.py --host <адреса сервера> --selftest
```

`--selftest` шле синтетичну сцену і друкує, що повернулось. Якщо в кінці буде
`ЗВʼЯЗОК ПРАЦЮЄ В ОБИДВА БОКИ`, значить усе з'єдналось і можна підставляти свої
дані.

## Найважливіше: що саме треба слати

Залежить від того, **чи має приймач свої VSLAM і FDE**. Домовтесь про це перед
тим, як починати, бо від цього залежить, чия це робота.

| поле | тип | хто дає |
|---|---|---|
| `depth` | `(H, W) float32`, метри | відправник, або приймач своїм FDE |
| `T_wc` | `(4, 4) float64`, камера у світ, метри | відправник, або приймач своїм VSLAM |
| `K` | `(3, 3) float64`, матриця камери | відправник, або приймач з калібрування |
| `landmarks` | `(N, 3) float32`, світові координати | **тільки VSLAM**, чий би він не був |
| `image` | `(H, W)` або `(H, W, 3)` uint8 | відправник |

Кадр має нести **щонайменше** або глибину, або картинку. Решту приймач може
порахувати сам, якщо в нього вставлені VSLAM і FDE.

`landmarks` це розріджені точки VSLAM, тобто ті, за якими він рахував своє
положення. Саме вони дають масштаб, яким виправляється щільна глибина від
нейромережі. **Без них карти ДОВІРИ не буде**, буде лише карта зайнятості.

Дві умови, інакше нічого не збіжиться:

1. `T_wc` і `landmarks` мають бути **в одній світовій системі координат**.
2. Усе **в метрах**. Монокулярний VSLAM свого масштабу не має, тож масштаб
   треба взяти з інерціального модуля, висотоміра або стерео. Сам конвеєр
   нічого не вирівнює і масштаб не відновлює.

`T_wc` це перетворення з системи камери у світ: `p_світ = T_wc @ p_камери`,
осі камери звичайні, тобто X праворуч, Y вниз, Z уперед.

## Як слати свої дані

```python
from client import Client

c = Client("192.168.0.122", port=9000, listen_port=9001)

for i, frame in enumerate(my_stream):
    c.send(i, frame.timestamp, frame.depth, frame.T_wc,
           K=frame.K, image=frame.grey, landmarks=frame.vslam_points)

    for m in c.results(timeout=0.2):
        if m["type"] == "conf2d":
            conf = m["confidence"]      # (H, W) float32, NaN = піксель відкинуто
        elif m["type"] == "grid_delta":
            m["idx"]        # (N, 3) int32, індекси змінених вокселів
            m["values"]     # (N,) float32, нові значення логарифма шансів
            m["dims"], m["origin"], m["resolution"]

c.close()
```

### Що означає те, що повертається

**`conf2d`** це карта довіри на кожен піксель цього кадру. Значення від 0 до 1:
наскільки можна вірити глибині саме в цьому пікселі. `NaN` означає, що піксель
відкинуто і в карту він не йде, наприклад небо.

Ймовірність зайнятості, яку цей кадр вносить у карту:

```python
P = 1 / (1 + np.exp(-0.85 * conf))     # від 0.50 до 0.70
```

Більше 0,70 з одного кадру бути не може за побудовою. Високі значення
накопичуються лише тоді, коли одне й те саме місце підтверджується з багатьох
кадрів.

**`grid_delta`** це ті вокселі, які цей кадр змінив. Не вся сітка, а приріст:
сітка 120 на 120 на 120 важить 6,9 МБ, а один кадр чіпає близько півтори тисячі
вокселів, тобто 24 КБ. Збирати карту з приростів так:

```python
import numpy as np
grid = None
for m in c.results():
    if m["type"] == "grid_delta":
        if grid is None:
            grid = np.zeros(m["dims"], np.float32)
        i = m["idx"]
        grid[i[:, 0], i[:, 1], i[:, 2]] = m["values"]

P = 1 / (1 + np.exp(-grid))     # ймовірність зайнятості вокселя
occupied = grid > 0             # поріг P > 0.5
```

Світові координати центра вокселя: `origin + (індекс + 0.5) * resolution`.

Кадр, який не змінив жодного вокселя, приросту не шле. Це нормально: коли
ділянка вже насичена, нових свідчень немає.

## Порти

За замовчуванням `9000` для кадрів і `9001` для відповіді. Змінюються
прапорцями `--port` і `--listen_port`.

Сервер відповідає **на ту адресу, з якої прийшли кадри**, тож свою IP наперед
повідомляти не треба.

---

## Якщо між нами інтернет, а не локальна мережа

Тоді бери TCP:

```bash
python client.py --host <адреса> --port 9000 --tcp --selftest
```

UDP тут не підходить, і це виміряно, а не припущення. Повідомлення ріжеться на
шматки, повторів немає, тому втрата **одного** шматка губить усе повідомлення:

| повідомлення | шматків | при 1 % втрат доходить |
|---|---|---|
| кадр, 700 КБ | 500 | **0,7 %** |
| карта довіри | 185 | 15,6 % |
| приріст вокселів | 18 | 83,5 % |

У локальній мережі втрат практично немає і UDP кращий, бо без затримок на
повтори. Через інтернет кадр доходив би цілим приблизно раз на сто п'ятдесят.

З TCP усе простіше ще й тому, що **одне з'єднання несе обидва напрямки**:
окремий порт для відповіді не потрібен, NAT з твого боку не заважає, бо
з'єднання встановлюєш ти.

У коді те саме, лише клас інший:

```python
from client import TcpClient
c = TcpClient("100.x.y.z", 9000)      # далі send і results як вище
```

## Якщо канал вузький

`--scale 2` зменшує глибину і зображення вдвічі перед відправкою, разом з
перерахунком матриці камери. Вчетверо менше байтів.

З боку сервера є дзеркальний важіль, який зменшує карту довіри перед
відправкою, про це скажи, якщо треба.

---

## Якщо нічого не повертається

1. Чи запущений сервер і чи досяжна адреса: `ping`, а для TCP ще й
   `telnet <адреса> 9000`.
2. Чи не блокує брандмауер потрібні порти.
3. Чи слухаєш ти той порт, який сервер вважає портом відповіді.
4. Чи є `landmarks`, від тебе або від VSLAM приймача. Без них сервер прийме
   кадр, але карти довіри не побудує і скаже про це у своєму лозі.
