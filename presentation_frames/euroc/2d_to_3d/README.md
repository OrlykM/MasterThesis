## Як відтворити

```bash
cd src && source ../.venv/bin/activate
python3 explain_2d_to_3d.py --n_frames 2600            # повний прогін
python3 explain_2d_to_3d.py --from_cache               # лише перемалювати
```

Скрипт не повторює конвеєр. Він запускає `occupancy_3d_map.run_dataset_mode` з
необов'язковими гачками `frame`, `grid_frame` і `grids`, які той приймає
порожніми за замовчуванням, і забирає проміжні величини прямо звідти. Тому
зворотна проєкція, калібрування, таблиця, маска лопатей, вето неба і накопичення
в логарифмі шансів тут ті самі функції, що в справжньому конвеєрі.
